### 🚀 Featured Project

**[SignalScout AI](https://github.com/abhijitmanna912001/mindstack-neathack)**: B2B prospecting agent that checks its own claims ([live beta](https://mindstack-neathack.vercel.app/results), invite-only)

It validates and deduplicates company records before any paid enrichment, then verifies every number in LLM-written outreach against cited facts and suppresses any draft that fails.

- Benchmarked baseline vs improved pipelines on 10 real records: drafts with citation violations fell from 4 to 0 and model cost dropped from $0.0272 to $0.0194, traced end to end with neatlogs
- Shipped on Vercel with hashed invite codes, per-IP rate limits, record and call caps and a database kill switch, backed by 829 Vitest tests
- Next.js, React, TypeScript, PostgreSQL, Tailwind CSS, Anthropic API, Crustdata API
